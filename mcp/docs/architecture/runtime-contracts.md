# 0.1.0 运行契约与边界

产品提供通用操作、图像和原始诊断事实。业务编排、文件实际读写校验、视觉解释、性能或发布判断由调用方负责。

## 接入和执行

对外唯一MCP为stdio网关。mcp默认本机LocalExecutor；select-machine指定IP使用HttpExecutor，包括显式127.0.0.1。被测电脑运行serve，默认IPv4接口7443/mcp，可维护配置listen/port。未发版的profile、旧命令别名、旧聚合SDK/API兼容层已移除。

Console、目标应用与Windows worker运行在执行电脑同一已登录用户交互桌面。HTTP当前为无Token内网模式；URL不能启动远端进程。目标应用在Avalonia初始化后Attach Agent，单个Agent同时接受一个诊断连接。

网关与HTTP端各自协商MCP，不把外层stdio的_meta原样转给HTTP。目前内部HTTP客户端使用2025-11-25有状态协议，外部stdio独立协商。选择候选先核验目录、角色和scope元数据，不执行写操作。

## 身份和切换

调用始终绑定开始时的执行会话。机器、应用、预览内容、native worker及资源各自有作用范围，相关范围更换后拒绝旧句柄。网关将后端ID视为不透明值，不解码其位段。

有在途操作或未终结原生动作时拒绝切换，避免阻断回答模态所需的native通道。准备候选失败明确保留原选择；成功提交退休旧句柄并结束旧会话，用户重新发现和附加目标。

远端断线不自动回本机，不重发可能已执行的操作。超时和取消不表示同步getter、控件处理器或OS动作已撤销；未知执行结果须显式报告。

客户端连接持有单调revision和peer专属通知源。跨重连晚到的响应或已捕获的旧通知delegate不得更新新会话。预览generation读取在await后核验revision，失败也不使用旧bridge回退。

## 并发与控制范围

managed调用共用当前目标的调用门；native/file-dialog使用独立worker IPC通道，文件修改动作另有串行化。不能在网关用全局大锁覆盖一次完整操作。

native只操作所选进程及可验证owned窗口；校验PID/start time、HWND生命周期、owner和UIA节点。原始native节点与managed节点不混用。网关HTTP把完整操作送到执行电脑，UIA不跨电脑运行。

原生动作可能返回pending/dispatched，后续状态和实际UI仍需观察。输入确认前检查作用范围和前台；输入失败清理本次仍按下的键/按钮，不掩盖原始异常。

## 临时修改与清理

属性覆盖保留原绑定，转换/验证失败保留原覆盖；unset释放本会话覆盖，字符串null表示真正null而非解除。资源修改指向原owner/key，冲突和恢复保留应用后来写入的值。

结束控制释放本会话的覆盖、伪类、资源编辑、导出流、拾取/焦点监听、覆盖层、事件、日志、指标、Profiler和断点。外部附加应用不归工具所有，不被detach终止；自建预览和worker由各自所有者回收。

采集复用当前连接，只停止仍属于本次采集的listener。部分启动失败清理本次已启动部分；停止成功后冻结，损失、读错、未订阅与空样本保持区别。

## 图片、资源和协议预算

图像使用MCP image内容，元数据包含实际尺寸、区域、坐标空间、来源和限制；HTTP和stdio路径保持一致，不返回远端路径代替像素。网关仅映射已声明身份字段，不重写原始metrics/logs/自定义JSON。

managed截图使用控件局部DIP和显式scale；最大边2048、最多2,097,152像素、PNG最多1MiB。native截图使用节点局部物理像素、PrintWindow表面，默认8,000,000结果像素，可设至16,000,000，PNG最多16MiB；不激活/恢复窗口或替换桌面截图。GPU/受保护等表面可能不完整。

内部Agent RPC为四字节小端长度和UTF8 JSON，正文1至4MiB，有界分片、串行写入，非法帧或断流结束会话。它不是外部MCP JSON-RPC。Contracts记录及集合必须注册源生成JSON元数据，不能仅依赖JIT反射。

完整资产导出保持长度和SHA-256验证；预览截断不等于完整文件。目标路径属于执行电脑，调用方需要本地文件时读取实际返回内容再保存。

## XAML预览和分发

项目评估使用真实MSBuild上下文，build=true明确构建成功后才启动预览。预览加载项目类型、App资源和所选XAML，不调用目标Main。初次非法文档失败；后续失败保留上次成功画面，成功重载退休受影响的内容引用。

程序集及依赖变化需重建和重新附加。取消、失败、目标切换和父进程退出回收自建候选。单exe通过独立Packaging工程内嵌完整自包含发布资产，运行时允许缓存解包与隔离进程；用户工程评估/构建仍需SDK。
