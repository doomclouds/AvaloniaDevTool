# DeveloperTools 功能与自研验收目录

> 历史研究：本文对应完整桌面产品基线 `main/fa1c623`，其中 GUI、外部后端、旧路线建议和阶段计数不作为当前分支交付范围或通过证据。保留它用于来源、许可和设计研究；当前官方 Agent/MCP 合同与原版证据边界见 [官方能力基准](../agent-tools/research/official-capabilities.md)，当前状态见 [实现状态](../implementation-status.md)。

本目录把公开工具说明拆成可验收的子功能，并把社区反馈、原版产物证据和自研设计分开。它用于后续 REA 取证与实现排期；完成标准是行为和测试，而不是出现同名按钮。

调查日期为 **2026 年 10 月 24 日**。公开功能基线覆盖 8 个 Tool Reference 页面，以及 Settings、Shortcuts、Options、各类连接、预览器和 MCP 页面；另核对产品版本矩阵、FAQ、发布文章及社区讨论。下表共有 **125 项公开说明中的能力或明确边界**，另有 **16 项原生绑定名字提供的待验证线索**。这代表本次读到的公开范围，不代表已经穷尽未公开实现。

## 版本、证据和状态口径

- 原版产物固定为已安装的 **2.2.3**。官方文档多数在 2026 年 10 月更新，可能描述晚于该产物的能力；公开说明不能直接证明 2.2.3 已实现该项。
- `C域` 表示官网归入 Community 的能力类别，`P` 表示官网明确列为 Plus；不是逐项实测的授权分支。官网当前描述 Community 面向非商业桌面检查，Plus 包括绑定诊断、日志、资源、资产、断点、3D、性能、远程／移动及 MCP。[O1]
- `V1状态` 统一对照上一版 **24 项测试通过**的自研基线：本机命名管道、分开的 Visual／Logical 树、属性诊断覆盖、拾取和高亮。此列不是并行开发中工作树的实时状态；后续应附测试或运行证据再更新。
- `待REA问题` 和 `自研验收` 是本项目的调查问题与设计要求，不声称是原版源码。`仅绑定名字` 只能证明字节内有声明候选，不能证明入口可用、执行路径或完整实现。
- Hot Reload、Parcel、IDE 扩展是相邻产品；本目录只纳入它们与 DevTools 连接、预览或诊断直接相关的接口，不把整个产品套件混作 DevTools 功能。

## 文档与产物差异需要单独验证

1. **MCP工具目录状态不同。** 当前文档列出 16 项，含 `detach`；本次对本机 2.2.3 在未附加目标的初始会话中执行 `initialize` 和 `tools/list`，只取得 15 项，未广告 `detach`。服务声明 `tools.listChanged=true`，仍需验证附加后是否动态出现；不能直接定性为2.2.3完全不支持。`tools/list` 成功也不代表受授权和目标条件约束的 `tools/call` 全部执行成功。[O16][N2]
2. **Browser自动连接说明不一致。** Options 写移动端默认自动连接、其他平台默认关闭；Attaching applications 却写 Browser 默认自动连接。应追踪实际默认值和初始化调用路径。[O5][O13]
3. **Gauge说明不一致。** Metrics 明确写当前不支持 Gauge，Settings 的聚合说明却提到 Gauge。应按实际 instrument 接收和图表路径判断，不能直接补写支持。[O11][O3]
4. **资源作用域因前端而异。** Resources GUI 文档排除控件及模板局部资源，MCP `resources` 则声明可按节点取作用域；两者不能合并成一个未经验证的全局资源浏览行为。[O9][O16]
5. **运行时与包目标框架要分开。** 安装页是概述；2.2.3 Runner 的 .NET 6 目标、SDK 的 net8/net10 变体及原生主程序是不同产物。SDK 前提与版本适配以实际 NuGet/程序集身份为准。[O18][O17]
6. **Profiler范围明确。** 详细页记录 Style Matching、Style Activators 和 Resource Lookup 三类聚合；不能据此宣称完整 CLR CPU、GC 或 EventPipe 采样分析。[O12]

## 分层推进建议

1. **对象与导航层**：祖先链、目标端搜索、Merged／模板模型、上下文属性和焦点跟踪。先补可定位性，避免后续事件、日志只能显示无法跳转的对象。
2. **属性解释层**：setter／ValueStore帧、绑定表达式及验证异常、嵌套对象与专用编辑器。沿用已验证的可撤销编辑和弱句柄，不把诊断修改写回绑定源。
3. **观测层**：有容量限制的路由事件／结构化日志及断点，保留单次事件的route身份和订阅生命周期。
4. **资源与图像层**：资源provider与作用域、资产流、元素截图和Composition快照。二进制大小、解码预算和取消应进入协议契约。
5. **时间维度与自动化层**：Meter／Activity、三类Profiler、MCP和预览器；复用同一Client服务，避免GUI和AI接口各写一套不同语义。

每一项完成时记录功能ID、接口／符号、产物哈希、REA Evidence ID或运行结果、测试名称和剩余差异。公开文档覆盖、字节声明、静态调用链、受控运行及自研测试是不同证据层级，不能互相替代。
