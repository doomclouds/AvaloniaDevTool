# 内嵌资产检查与导出

资产面板枚举目标进程已加载程序集的 `AvaloniaResource`，可按 URI 或程序集筛选。`复制 URI` 将当前 `avares://` 地址写入 Inspector 窗口剪贴板。`导出原始文件` 使用窗口的保存对话框选择本地路径；取消对话框不写文件。只有保存对话框的明确选择允许覆盖。不会推测或写入业务源码目录。

## 预览与元数据

预览最多读取文件前 1 MiB，加 1 字节判断是否截断。文本保留原始 UTF-8 内容，截断边界不显示半个字符；JSON 转义后另有 3 MiB 文本预算，避免超过 RPC 的 4 MiB 帧上限。文本控件显示前 64 Ki 字符以限制排版内存。元数据显示原始大小、读取的预览字节数和截断说明；不支持长度的流明确显示原始大小未知，不把预览字节数冒充完整大小。

PNG、JPEG、GIF、BMP 和 WebP 先检查有界文件头并显示格式、像素尺寸及已声明 DPI；没有 DPI 声明时显示未知。RGBA 内存估算为宽 × 高 × 4，单独注明它不含解码器、行对齐、字体或绘制缓存，不能视作目标进程实际内存。只有完整且不超过 16 Mi 像素、单边不超过 32768 的图像才交给解码器。图像无效时显示原因，仍可导出原始字节。SVG 显示源码。

完整 TTF/OTF 字体从目标传回的实际字节创建独立字体集合，使用解码器返回的家族名显示样本文字；元数据保留来源 URI。切换或清空资产、断开或释放 Inspector 会移除并释放该字体集合。无效字体、截断字体和暂不支持的 WOFF/WOFF2 显示原因，不把二进制字体当作文本。字体测试及示例使用官方 `Avalonia.Fonts.Inter` 包的资源，不拷贝本机系统字体。

## 完整文件传输

完整导出独立于预览。`assets.export.begin` 创建只属于当前会话的随机 token；`assets.export.read` 按字节偏移顺序每次读取至多 64 KiB；最终块返回完整长度和 SHA-256。客户端同时计算长度、SHA-256 并验证后才报告完成。Base64/JSON 只携带一个小块，不把整份文件塞进一帧。

每个会话最多保留两个读取流，闲置两分钟自动释放，单份完整导出上限 100 MiB。超限、源流读取失败、目的流写入失败、用户取消和断开连接都关闭读取流。非 seek 流同样逐块读取并在 EOF 确定真实长度；超过总上限时失败并释放，不先分配整份内存。

客户端 `ExportAssetAsync` 向调用方拥有的可写流传输，不替调用方关闭目的流。`ExportAssetToFileAsync` 在同目录新建随机临时文件，完成校验后原子移动到明确指定的路径；失败/取消删除临时文件并保留已有文件。默认禁止覆盖，只有调用方显式传入 `overwrite: true` 才覆盖。

Agent 仅接受 `avares`，并核对 URI 属于目标进程已加载且含 Avalonia 内嵌资源的程序集、资源确实存在；拒绝查询参数、片段、文件路径及网络 URI。旧 `OpenAssetAsync` 保持可用，`ByteLength` 仍表示预览读取字节数；新增 `TotalByteLength` 表示有证据的原始长度，`IsTruncated` 对字节或传输文本预算截断均保持真实。

## 验证

Agent 的 `AssetExportTests` / `AssetPreviewTests` 验证真实命名管道的超过 1 MiB 文件完整导出、原始字节与 SHA-256、一连串取消/写入失败后的恢复、文件覆盖保护与临时清理、URI 限制、非 seek 流、TTL、并发数及总大小上限、UTF-8 边界、转义帧预算、图像元数据/解码预算，以及真实/无效字体。

Inspector 的 `AssetPreviewTests` 验证可见按钮与进度/状态、窗口剪贴板、保存对话框取消、完整导出与取消、真实字体家族渲染及集合释放，以及实际 PNG 像素预览。操作系统原生保存对话框和实际桌面呈现仍需桌面验收。
