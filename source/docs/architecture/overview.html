AvaloniaDevTool 能力域与分层

一个 MCP 配置、默认本机、指定 IP 切换执行电脑。整个解决方案统一分层，能力对象独立拥有状态，远端 Console 复用相同执行目录。此页离线可读，源码与构建关系以链接文档和 csproj 为准。

唯一 stdio MCP，两种内部执行路径

Codex → stdio → 统一网关：外部目录固定，机器选择不改变用户工具参数。
默认本机
↓

↓
本机 Agent / NativeWorker / Previewer
指定 IP（含 127.0.0.1）
↓
HttpExecutor → HTTP MCP → serve Console
↓
该电脑的 Agent / NativeWorker / Previewer

Console 只直接执行，不再次选择机器。图片以实际 image 内容与元数据返回，路径属于执行电脑。回环测试必须经过完整 HTTP，不能优化为 LocalExecutor。

控制台不编译引用 Avalonia/UIA。Agent 不引用 MCP/执行宿主。Windows 原生依赖留在 worker。打包关系不是编译引用，RPC 使用真实 Infrastructure.Rpc 程序集身份。

能力域及主要状态

目标与会话

选择和附加目标、控制范围、切换及结束。网关持机器范围，执行端持应用范围，旧句柄不能跨范围复用。

结构与对象检查

树、搜索、祖先、分页、对象下钻；TreeInspectionService 拥有 MergedTree、分支观察与版本。

属性与样式

属性、绑定、样式、伪类、临时覆盖和恢复；属性服务拥有覆盖、预览租约和上下文，样式服务拥有伪类状态。

资源与资产

资源字典查询和临时编辑；嵌入资产查看与完整导出。二者保留独立语义和数据。

框架交互

文本、键鼠、拖动、选择、动作与等待。操作回执不等于应用业务成功。

原生自动化

共享 NativeTargetRuntime，独立 Query / Action / Input，节点和窗口身份只在执行端维护。

文件选择对话

Domain 文件弹窗流程通过 INativeAutomationTarget 复用 native；维护路径、过滤器、确认、取消、覆盖与状态。

图像与视觉诊断

managed/native PNG、布局、合成、覆盖层和弹层冻结。图片内容和尺寸/坐标/限制一起返回，不做视觉验收。

运行诊断

日志、事件、Metrics、Profiler、断点及采集。CaptureCoordinator 协调来源，mutation tracker 防止停止别人后来启动的监听。

XAML 预览

从项目上下文创建可调试目标；保存重载，失败保留最后成功画面，成功内容替换使相应旧节点失效。

组合入口与能力对象

GatewaySession → 当前执行器 + GatewayHandleRegistry + NativeOperationTracker
ToolSession    → 当前客户端 + 发现 + NativeSessionOwner + 采集协调 + OwnedPreview
DiagnosticsClient → Connection + 17 个能力客户端（旧平铺 API 已删除）
AgentSession   → 树 / 属性 / 样式 / 选择 / 截图 / 诊断服务 + 公共身份/观察
NativeBackend  → Query / Action / Input / Screenshot + 共享目标运行时

生产手写 partial 已移除，JSON 源生成 partial 保留。切换忙时拒绝，不堵塞 native 回答模态；失联不回退本机，修改请求不自动重放。每个能力释放自己的临时状态，组合根只协调顺序。

单 exe 分发与用户目录版本安装

独立发布 Console、Previewer、NativeWorker 的自包含目录
  → 压缩 + 文件清单 / SHA-256
  → Packaging 内嵌资源
  → AvaloniaDevTool.exe
  → 校验缓存并按需启动内部进程

用户只分发一个 exe；运行时允许缓存文件和多个进程。用户工程评估/构建仍需 SDK，目标应用仍需接入 Agent。

pwsh -File build/Build-Bundle.ps1 -Version 0.1.0
pwsh -File tools/Install-AvaloniaDevTool.ps1 -PackagePath .\artifacts\package\win-x64\AvaloniaDevTool.exe -Version 0.1.0

%USERPROFILE%\.local\share\avalonia-devtool\versions\<版本>\AvaloniaDevTool.exe
%USERPROFILE%\.local\bin\AvaloniaDevTool.exe  ← 用户 PATH 稳定入口
