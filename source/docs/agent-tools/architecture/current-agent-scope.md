# 当前 Agent 范围

核对日期：2026-10-27。本页固定当前产品边界；旧架构、研究或验证文档中超出本页的“后续计划”不再构成交付要求。源码和测试的最新结果以 [实现状态](../../implementation-status.md)、[测试说明](../../testing.md) 及对应证据为准。

产品目标是通过 MCP 提供通用自动化操作与可观察数据。调用方依据这些数据关联业务、解释结果并作出判断。代表性业务场景和脚本用于研发验证工具能力，不建设业务验收框架。

## 范围内

| 能力 | 完成边界 |
| --- | --- |
| 连接、预览与观察 | 附加真实应用或 XAML 预览，读取控件树、属性、样式、资源、资产及状态；明确目标、节点身份和错误。 |
| 通用界面操作 | Avalonia 文本、键盘、指针、选择、provider 动作、条件等待，以及 Windows 目标范围内的 UIA/OS 操作；不赋予业务含义。 |
| 真实文件弹窗 | 通过真实 Windows 公共文件弹窗完成打开/多选/目录/保存/过滤器/覆盖确认/取消。工具操作弹窗，调用方判断应用实际读写结果。 |
| PNG | 控件、窗口、区域的真实 PNG 及尺寸、区域、坐标空间和采集限制。 |
| 原始诊断数据 | 同连接采集 metrics、样式/资源 Profiler、logs/events，保留原始值、身份、采集范围、预算、损失与错误；调用方自行关联业务、分析数据。 |
| 工具可靠性 | 目标/owner 边界、旧 ID 拒绝、有界参数和等待、取消/超时、worker 生命周期与本会话资源清理。 |

`attach-to-file` 是 XAML 预览入口，不是文件选择器。框架输入、OS 输入与原生弹窗分别保留自己的节点/坐标合同；工具回执不自动等于应用业务成功。

## 当前状态

| 状态 | 内容 |
| --- | --- |
| 已有 | 0.1.0统一执行目录88项；stdio网关额外提供select-machine，共89项。原有独有诊断能力已纳入，未发布的profiles与旧兼容API删除。准确参数以当前tools/list为准。 |
| 本轮专项已验证 | 同连接 capture 的原始数据/故障 RPC；ui-screenshot 控件/区域渲染；native-screenshot 真实 WinForms 和 stdio MCP 的主窗、CommonItemDialog/路径框区域及无效/stale 拒绝。实际 PNG 已人工查看；几何单测与运行截图分别记录。 |
| 最新验证 | 0.1.0新增网关、分层、会话隔离、单文件分发和安装分别验收；实际结果见[测试说明](../../testing.md)，历史批次不作为本轮结果。 |
| 仍需按证据确认 | Windows 已实现路径中的未实测分支，例如真实 PID 循环、强制 OS 部分输入失败与清理；完整根 HWND 复用已在后续独立 Explicit 通过，动作首访问顺序等局限仍保留。应按真实 OS/合成 provider 等证据层记录，不能由常规测试总数推导。 |

已有状态不表示所有平台、provider、应用或失败分支都支持。当前 native 后端限 Windows；文件弹窗控制器只匹配已验证的公共文件弹窗结构，自绘或第三方 picker 结构不匹配时明确失败。所有当前能力采用一套工具合同，不保留未发布的兼容profile。

PNG 返回 image 与尺寸/坐标/方式等元数据。ui 截图按控件局部 DIP/显式 scale 渲染；native 截图按节点局部物理像素使用 PrintWindow，不激活/恢复窗口或回退桌面抓屏，GPU/受保护等内容可能不完整。参数与预算见 [PNG 合同](../features/agent-interaction.md#png-截图)。

## 明确排除

| 排除项 | 当前决定 |
| --- | --- |
| 业务场景产品化 | 不提供 run-scenario、版本化业务脚本语言、业务断言引擎或统一业务验收框架；调用方可自行编排通用工具。 |
| 视觉判断 | 不做视觉比对、视觉基线、图像容差或视觉通过判定；提供 PNG。 |
| 性能/发布判断 | 不做业务性能阈值、性能通过/失败、发版门禁、CI 或发布平台；提供原始诊断数据。 |
| 官方授权运行等价 | 用户不做原版授权运行对照；保留公开合同、schema 和必要研究，不将授权等价列为待完成阻塞。 |
| macOS/Linux 原生后端 | 用户不做其他平台的原生窗口、OS 输入与文件弹窗；Windows 证据不扩展为跨平台承诺。 |
| 完整性能剖析 | 完整 CPU 调用栈与内存分配剖析交由其他工具；本项目 Profiler 限样式/资源活动。 |
| 复杂输入/传输 | IME 候选/组合输入及系统文件/数据 DragDrop 暂不做；Unicode 注入、普通指针拖动不能视为这些能力。 |

“排除”不计入当前产品的待完成清单。未来只有用户改变范围后才重新进入计划。

## 研发验证与完成口径

研发脚本和代表性业务流程只用于验证通用操作、原始数据和错误边界。例如通过真实打开/保存核对文件字节，可证明该次文件工具链路可用；不能据此承诺任意应用的业务验收能力。验证矩阵与可核对标准见 [自动化能力与研发验证边界](automation-and-acceptance.md)。

完成报告应同时写明：该构建实际工具表、实现范围、已执行验证及其证据层、剩余未实测分支。历史总数不挪作本轮结果；未运行的 GUI/OS 路径不借用 Headless 或合成输入结果宣称通过。功能数量、测试数量和研究条目各用各的口径，不计算统一产品完成百分比。
